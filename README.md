# Desafio de POO — Sistema Bancário

## Desafio

Desenvolva um sistema bancário utilizando Programação Orientada a Objetos. O sistema deverá trabalhar com diferentes tipos de conta, cada um com regras próprias para suas operações.

## Objetivo

Aplicar os quatro pilares da POO em uma solução funcional, organizada e de fácil compreensão.

## Requisitos

A solução deverá:

- cadastrar contas com titular e saldo;
- permitir depósitos e saques;
- possuir pelo menos dois tipos de conta;
- aplicar uma regra de saque diferente para cada tipo;
- impedir operações com valores inválidos;
- impedir que uma operação deixe o saldo negativo;
- informar quando uma operação não puder ser realizada;
- exibir os dados atualizados das contas.

## Quatro pilares

- **Encapsulamento:** proteja os dados internos das contas.
- **Abstração:** represente em um único conceito as características comuns entre as contas.
- **Herança:** reutilize as características comuns nos diferentes tipos de conta.
- **Polimorfismo:** permita que a mesma operação tenha comportamentos diferentes conforme o tipo da conta.


## Avaliação

Serão considerados:

- funcionamento da solução;
- aplicação dos quatro pilares da POO;
- tratamento das regras de negócio;
- organização e legibilidade do código;
- clareza das responsabilidades.
